# LadoRani-Creation-Web

Official website for **Lado Rani Creation** — Digital Textile Printing & Transfer Paper Printing in Surat, Gujarat.

## Tech Stack
- React 19 + Vite
- Lucide React
- React Router

## Scripts
- `npm run dev`: Start local development server
- `npm run build`: Build for production with SSR/prerender
- `npm run preview`: Preview production build
